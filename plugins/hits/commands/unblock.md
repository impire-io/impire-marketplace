---
description: Lift the block on a hits item, restoring the status it interrupted
argument-hint: "<item id>"
---

Unblock item $ARGUMENTS (`unblock_item` via the hits MCP tools, or `hits unblock`). The record restores the exact status the block interrupted — never transition to it manually.

Append a note saying how the blocker resolved, so the trail explains the gap. Then report the restored status and, if the user is picking the work back up, continue as /hits:work.
