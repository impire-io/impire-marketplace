---
description: Append a note to a hits item's trail
argument-hint: "<item id> <the note>"
---

Append the note in $ARGUMENTS to the named item's trail (`note_item` via the hits MCP tools, or `hits note`).

Notes are append-only history — hypotheses, evidence, dead ends, closing reasoning — written for the next reader. Never rewrite or retract one; a correction is a new note saying what the earlier one got wrong. If the text reads like a change to the report or the item's fields rather than trail history, use an edit instead and say so.
